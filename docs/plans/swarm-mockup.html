Parameter values: the mock-up assumes every parameter's preset value is 50%. A dot at its box centre leaves it there; moving the dot away from its box centre adds to or takes from it (the box edge = plus or minus 50% of the range, the far screen edge more, all clamped to 0..100%). So the POSITION knob is a manual bias, and the shape moves the value around it.
The four sliders are K1..K4 and always mean dot 1..4. SELECT (the row buttons) changes which parameter they set. Box order assumed: 1 top-left, 2 top-right, 3 bottom-left, 4 bottom-right. POSITION: 50% = box centre; below 50% the centre slides down the box's vertical line, popping to the top at 25%; above 50% it slides left to right along the horizontal line, popping to the left at 75%; 0, 50 and 100% are all the centre.
